## The idea

J.P. Morgan is supposed to have said that millionaires don't use astrology but billionaires
do. This project takes the claim seriously enough to *measure* it — and builds the
instrument that would be needed to measure it properly.

The Vedic astronomical tradition, **Jyotiṣa**, is at bottom a system of precise cyclic time-
keeping: the Moon's 27 nakṣatras, the 30 tithis of the lunar month, the 120-year Vimśottarī
daśā, the Aṣṭakavarga bindu tables. Strip away the metaphysics and what remains is a set of
deterministic, arc-second-precision temporal coordinates that no market participant is
using as features. That is genuinely unexplored territory, and it has one property no
technical indicator has: **it is computable arbitrarily far into the future.**

## What's actually new here

**ChandraQuant v1** (the prior version, documented in `ML_ProjectReport.pdf`) fed a Random
Forest 10 astro features — Moon longitude, Sun longitude, Tithi, Nakṣatra and harmonics.
Every one was a function of *calendar date alone*. Pooled across three indices, each astro
row therefore appeared three times against three different labels, and the astro block was
**mathematically incapable of discriminating between the indices**. It measured ΔAUC
**−0.018**: the hybrid model was *worse* than technical-only.

**v3 fixes this at the root with mundane (natal) astrology.** An index is born the day it
begins publishing. Cast a chart for that moment and place, and every celestial position
becomes a **transit relative to that chart**:

| Index | Born | Natal Moon nakṣatra | Lagna |
|---|---|---|---|
| NIFTY 50 | 1996-04-22 10:00 IST | Mṛgaśīrṣa (Maṅgala) | Mithuna |
| BANKNIFTY | 2003-09-15 10:00 IST | Bharaṇī (Śukra) | Tula |
| CNX IT | 1999-05-11 10:00 IST | Pūrva Bhādrapadā (Guru) | Mithuna |

On **2026-08-28** the same sky reads three different ways: NIFTY sits in **Sampat tārā**
(+0.9, wealth-giving), BANKNIFTY in **Pratyari** (−0.7, obstruction) *and* under **Sade
Sati**, CNX IT in **Ati-Mitra** (+1.0). **188 of 831 features now differ between tickers.
In v1 that number was zero.**

This unlocks the entire classical apparatus v1 never touched: Vimśottarī Daśā, Sade Sati,
Tārābala, Chandrabala, Aṣṭakavarga, and Gochara through natal bhāvas.

## Results

Backtest 2010-01-04 → 2026-08-28, daily bars, 5 bps per side, next-bar execution,
purged walk-forward validation. Every figure is generated by `scripts/backtest.py` into
`artifacts/metrics.json` — nothing in this table is typed by hand.

| | **NIFTY 50** | **BANKNIFTY** | **CNX IT** |
|---|---|---|---|
| CAGR | 8.35% *(B&H 9.63%)* | 8.49% *(11.70%)* | **15.06%** *(10.57%)* |
| Sharpe | **0.66** *(0.66)* | **0.66** *(0.61)* | **0.68** *(0.59)* |
| Max drawdown | **−21.6%** *(−38.4%)* | **−22.3%** *(−47.9%)* | **−40.2%** *(−44.0%)* |
| **Calmar** | **0.39** *(0.25)* | **0.38** *(0.25)* | **0.38** *(0.24)* |

**The headline: Calmar 0.38–0.39 against a 0.24–0.25 benchmark — roughly 55% better
return per unit of drawdown, on all three indices, with maximum drawdown nearly halved
on NIFTY and BANKNIFTY.**

### Where the astro layer genuinely shows up

During the **COVID crash**, the astro-only model beat the technical model outright:

| COVID (Feb–Jun 2020), out-of-fold AUC | Technical | **Astro-only** | Hybrid |
|---|---|---|---|
| BANKNIFTY | 0.611 | **0.719** | **0.760** |
| CNX IT | 0.489 | **0.647** | 0.573 |

This is the "crisis alpha" hypothesis from the original paper actually appearing in the
data: when price history stops being informative, an orthogonal clock retains structure.
Sample sizes are small and this is not claimed as proof — see
[`docs/METHODOLOGY.md`](docs/METHODOLOGY.md), which reports the negative results too.

## The Jyotiṣa engine

Twelve modules, 831 features, all deterministic functions of date and natal chart.

| Module | Delivers |
|---|---|
| `ayanamsa` | Lahiri (Chitrapakṣa) via IAU-2006 precession |
| `ephemeris` | Skyfield / JPL DE440s apparent sidereal positions, speeds, nodes |
| `panchanga` | Tithi (30), Vāra, Nakṣatra (27 × 4 pādas), Yoga (27), Karaṇa (11/60) |
| `lunar` | phase, Chandra Śara, gaṇḍānta, sandhi, gati, tidal force, Kriyā/Avasthā/Velā |
| `solar` | Saṅkrānti ingress, Uttarāyaṇa, declination, Ṛtu, Māsa |
| `grahas` | dignity, uccha bala, Vakrī, Stambhana, Asta, Graha Yuddha |
| `aspects` | Parāśarī dṛṣṭi, orb-decayed kernels, 9 named market yogas, Kemadruma |
| `events` | true eclipses, Gochara ingress, stations, Great Conjunction |
| `natal` | **Lagna, Gochara, Tārābala, Chandrabala, Sade Sati, bhāva activation** |
| `dasha` | Vimśottarī Mahā/Antar/Pratyantar chain from each index's natal Moon |
| `ashtakavarga` | Bhinnāṣṭakavarga + Sarvāṣṭakavarga transit strength |
| `shadbala` | Ṣaḍbala in rūpas: Sthāna, Dig, Kāla, Cheṣṭā, Naisargika, Dṛk |

Collapsed into five branded readouts: **CBI** (Chandra Bala), **GSI** (Graha Śakti),
**VRI** (Vṛddhi), **BHY** (Bhaya/panic), **KTW** (Kāla Taraṅga — the cosmic tide).

### Verified against external ground truth

The engine isn't merely self-consistent — every claim is anchored outside this repo:

- **Eclipses: 8/8 exact date match against the NASA catalogue for 2025–26, zero false
  positives**, 4.78/year over 2018–2026
- **Makar Saṅkrānti 2025-01-14**: Sun at sidereal 270.009° — exactly entering Makara
- **Great Conjunction**: minimum Guru–Śani separation 2020-12-22, 0.04° (actual 2020-12-21)
- **Budha vakrī 2025** detected 03-16 / 07-19 / 11-10 vs actual stations 03-15 / 07-18 / 11-09
- **Ascendant formula**: at Mumbai sunrise the Lagna equals the Sun's longitude to 0.9° —
  precisely the refraction + semi-diameter offset that *defines* sunrise
- **Aṣṭakavarga**: BAV totals 48/49/39/54/56/52/39, SAV grand total exactly 337
- Diwali 2024 & 2025 both resolve to Kṛṣṇa Chaturdaśī with the correct nakṣatra

`pytest` — **60 tests, all passing.**

## TradingView

Two Pine v6 scripts in [`pine/`](pine/). They compute **real astronomy on the chart**:
Sun and Moon ecliptic longitudes from Meeus periodic series evaluated natively in Pine,
converted to the sidereal zodiac with Lahiri ayanāṁśa. No ephemeris file, no expiry date,
works on any bar past or future.

Validated against Skyfield/DE440s over 1,253 samples spanning 2007–2030:

| | max error | nakṣatra / tithi / rāśi agreement |
|---|---|---|
| Sūrya | 0.0095° | **100%** |
| Chandra | 0.0236° | **100%** |

- **`ChandraQuant_KalaChakra.pine`** — regime bands, nakṣatra markers, Pūrṇimā/Amāvāsyā
  glyphs, Grahaṇa shading, Viṣṭi hatching, live pañchāṅga table, Kāla-Taraṅga oscillator
- **`ChandraQuant_Strategy.pine`** — backtestable, with the Jyotiṣa layer as a toggleable
  **abstention gate** so you can measure exactly what it contributes

## Install and run

```bash
pip install -e .
python scripts/refresh_data.py --all     # pull OHLCV, write offline snapshot
python scripts/optimize.py               # tune per-ticker strategy parameters
python scripts/backtest.py               # → artifacts/metrics.json
python scripts/validate.py               # → artifacts/validation.json
pytest -q                                # 60 tests

chandraquant                             # picker → dashboard
chandraquant --ticker NIFTY --date 2020-03-23   # replay the COVID bottom
chandraquant --honest                    # unconditional metrics and caveats
```

The app **works offline**. A live Yahoo refresh is attempted with an 8-second timeout;
on any failure it falls back silently to the committed snapshot and the header reports
`○ cached` rather than pretending.

## Honesty

This README leads with the results that hold up. The ones that don't are in
[`docs/METHODOLOGY.md`](docs/METHODOLOGY.md) and behind `chandraquant --honest`, and the
short version is this: **measured out-of-sample, celestial state does not reliably predict
Indian index returns.** The astro block reaches AUC ~0.50, its conditional edges are not
stationary across walk-forward folds, permutation tests do not clear p < 0.05, and the
hand-assigned classical biases I started with backtested as *actively harmful*.

So position sizing is trend + volatility targeting, and the Jyotiṣa engine drives regime
narrative, the forward calendar, the composite indices and the Pine visuals. The forward
calendar is the one place where it is a genuine forecast rather than a fit — astro features
are functions of time alone, so next month's celestial calendar is exactly as certain as
last month's.

That distinction is the most interesting thing the project has to say, and burying it
would have made the work worth less, not more.
